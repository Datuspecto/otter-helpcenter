오터포스는 **여러 배달앱의 주문을 한 화면에 모아 관리하는 배달 전용 포스**입니다.  
배달앱마다 각각 주문내역을 처리하는 것이 아닌, 배달·포장·전화·내점 주문을 한 곳에서 처리하실 수 있습니다.

## 주요 기능

- **주문 통합 관리**  
    배달앱 주문부터 포장·전화·내점 주문까지 **모든 주문을 한 화면에서 통합해 접수하고 관리할 수 있습니다.**  
    샵인샵 등 **사업자등록번호가 여러 개인 매장도 하나의 프로그램에서 통합 관리할 수 있습니다.**

- **주문 자동 수락**  
    설정한 **조리시간을 기준으로 주문이 자동 수락됩니다.** 주문이 수락되면 영수증이 자동으로 출력되므로, **영수증을 확인한 후 조리를 시작해 주세요.**

- **배달대행 자동 배차**  
    연동된 배달대행사로 **배차 요청이 자동으로 전송됩니다.**  
    자동 배차를 설정하면 **주문 수락과 동시에 배차 요청까지 자동으로 진행됩니다.**

- **리뷰 통합 관리**  
    배달앱 3사의 **리뷰를 한 화면에서 확인하고 답글을 작성할 수 있습니다.**  
    **자동 답변을 설정하면 리뷰에 대한 답글도 자동으로 등록할 수 있습니다.**

- **매출 분석**  
    배달앱별 **매출, 인기 메뉴, 놓친 주문 현황을 날짜별로 확인하실 수 있습니다.**  
    더 자세한 매출 및 운영 데이터 분석은 별도 웹 사이트인 [비즈니스 매니저](/help/biz-manager/access) 에서 제공됩니다.

## 사용 환경

| 환경 | 지원 여부 |
| --- | --- |
| 윈도우 설치 프로그램 | 지원 (Windows 10 이상) |
| 웹 브라우저 (app.tryotter.com) | 지원 |
| 안드로이드 앱 | 지원 |

설치형 프로그램은 **Windows 환경에서만 이용하실 수 있습니다.**  
매장 밖에서는 **웹 브라우저 또는 Android 앱을 통해 주문을 접수하고 관리하실 수 있습니다.**

## 시작하려면

[오터포스 신청 방법](/help/getting-started/apply)을 확인해 주세요. 프로그램 설치 후 **30일간 무료로 이용하실 수 있습니다.**

---

**예외 안내**

- **인터넷 연결이 필요합니다.** 오터포스는 인터넷이 연결된 환경에서만 사용하실 수 있습니다.
- **사업자등록번호가 필요합니다.** 사업자등록번호가 없으면 서비스를 이용하실 수 없습니다.
- **샵인샵·다중사업자 매장도 가입하실 수 있습니다.** 사업자등록번호가 여러 개여도 하나의 오터포스로 통합해 관리합니다. 사업자 수에 따라 요금이 추가되며, 자세한 내용은 [오터포스 이용요금 안내](/help/pricing/pricing-guide)를 확인해 주세요.
