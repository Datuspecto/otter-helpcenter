비즈니스 매니저에 **접속하거나 로그인 시 오늘의 매출 현황을 한눈에 확인하실 수 있습니다.**

## 화면 구성

![비즈니스 매니저 메인 화면](/images/img-46.png)

**상단 왼쪽 — 메뉴[메뉴]** 버튼을 누르면 다른 화면으로 이동합니다.

- **인사이트** — 매출·운영·메뉴 분석
- **주문 내역** — 주문별 상세 조회

**상단 오른쪽 — 알림과 설정**

- **알림(종 모양)** — 오터에서 공지하는 내용을 확인합니다.
- **설정(사람 모양)** — 계정 관련 설정을 변경합니다.

## 오늘의 매출 확인하기

화면 왼쪽에는 **오늘의 총 주문금액**이 표시되며, 오른쪽에서는 **시간대별 매출 그래프를 0시부터 23시까지 한눈에 확인하실 수 있습니다.**

그래프 오른쪽 아래 **토글을 켜면 지난주 같은 요일의 매출과 비교할 수 있습니다.**  
전날 매출과 비교하는 것보다 **요일별 매출 특성을 반영해 더욱 정확하게 비교하실 수 있습니다.**

## 필터로 좁혀 보기

그래프 위쪽 세 개의 선택 항목으로 범위를 좁히실 수 있습니다.

| 필터 | 용도 |
| --- | --- |
| Brands | 샵인샵 브랜드별로 나누어 확인합니다. |
| Locations | 지점별로 나누어 확인합니다. |
| 전체채널 | 배달앱 플랫폼별로 나누어 확인합니다. |

샵인샵이나 여러 브랜드를 운영하시는 경우 **원하는 브랜드를 선택해 매출을 확인하실 수 있습니다.**

## 바로가기

- **[애널리틱스 바로가기]** — 인사이트 화면으로 이동합니다.
- **[전일 매출 리포트 보기]** — 어제 매출 리포트를 확인합니다.

화면을 아래로 내리시면 **오늘의 주문 및 매출**이 나옵니다. [주문보기] 또는 [매출보기]를 누르면 상세 내역으로 이동합니다.
