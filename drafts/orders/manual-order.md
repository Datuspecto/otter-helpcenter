전화 주문 또는 방문 포장 주문을 **오터포스에 직접 입력하여 편리하게 관리하실 수 있습니다.**  
직접 접수한 주문도 **배달앱 주문과 동일한 화면에서 함께 확인하고 처리할 수 있습니다.**

## 주문 생성하기

![수기 접수 화면](/images/img-07.png)

### 1\. 메뉴 선택

메뉴 카테고리를 선택한 후 **주문 메뉴를 선택합니다.**  
옵션이 있는 메뉴는 **필요한 옵션까지 함께 선택합니다.**

### 2\. 가맹점 선택

샵인샵처럼 **사업자가 여러 개인 매장은 좌측 상단에서 주문할 가맹점을 먼저 선택합니다.**

### 3\. 배달 · 포장 선택

우측 목록에서 **선택한 메뉴와 금액을 확인합니다.**  
내용을 수정해야 하는 경우, **하단의 버튼을 이용해 변경할 수 있습니다.**

### 4\. 주문 내역 확인

우측 목록에서 선택한 메뉴와 금액을 확인합니다. 아래 버튼으로 수정하실 수 있습니다.

| 버튼 | 기능 |
| --- | --- |
| 전체삭제 | 선택한 메뉴와 옵션을 모두 삭제합니다. |
| 옵션수정 | 선택한 메뉴의 옵션을 변경합니다. |
| − / + | 선택한 메뉴의 수량을 조정합니다. |

### 5\. 주문 정보 입력

**[주문 정보 입력]** 버튼을 눌러 필요한 정보를 채웁니다. 배달과 포장이 다릅니다.

| 주문 유형 | 입력 항목 |
| --- | --- |
| 포장 | 픽업시간 (20분 단위로 선택) |
| 배달 | 전화번호, 주소 (필수) |

전화번호는 **010 또는 지역번호를 포함해 입력합니다.**  
주소는 **도로명 또는 지번으로 검색하여 입력하실 수 있습니다.**

![주문생성 버튼](/images/img-09.png)

### 6\. 주문 생성

모든 정보를 입력한 후 **[주문생성] 버튼을 누르면 주문이 접수됩니다.**

## 입력 중 취소하기

작성 중인 주문을 취소하려면 **화면 왼쪽 상단의 [<] 뒤로가기 버튼을 누릅니다.**

---

**예외 안내**

- **수기 주문만 수정할 수 있습니다.** 배달앱에서 들어온 주문은 내용을 수정하실 수 없습니다. 수기로 접수한 주문만 [주문 취소하기](/help/orders/cancel-order) 화면에서 수정이 가능합니다.
- **전화 주문 고객 정보** — CID를 연동하시면 걸려온 번호로 고객 정보를 불러올 수 있습니다. [전화주문(CID) 연동하기](/help/integrations/van-cid)를 확인해 주세요.
