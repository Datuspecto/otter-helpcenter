규칙과 답변 문구를 미리 등록해 두면 **리뷰에 대한 답글을 자동으로 작성하고 등록할 수 있습니다.**  
별점이나 사진 첨부 여부 등 **리뷰 조건에 따라 서로 다른 답변을 보내도록 설정할 수도 있습니다.**

설정 순서는 **[자동 답변 추가] → [규칙 설정] → [템플릿 등록]**입니다.

## 1\. 자동 답변 추가하기

1. 좌측 상단 **[메뉴]** > **[리뷰 관리]** 순서로 이동합니다.
2. 좌측 **[자동 답변]** 메뉴를 누릅니다.
3. 화면 중앙의 **[자동 답변 추가]** 버튼을 누릅니다.

## 2\. 규칙 설정하기

어떤 리뷰에 어떤 답글을 달지 정하는 단계입니다.

| 규칙 | 선택할 수 있는 값 |
| --- | --- |
| 사업자 규칙 | 전체 동일 / 각 브랜드별 / 각 지점별 |
| 배달앱 규칙 | 전체 동일 / 각 배달앱별 |
| 별점 규칙 | 전체 동일 / 별점별 |
| 내용 유무 규칙 | 별점만 있는 리뷰 / 별점과 내용이 함께 있는 리뷰 |
| 사진 유무 규칙 | 사진이 있는 리뷰 / 사진이 없는 리뷰 |
| 답변 시간 규칙 | 답변을 생성할 시간 |
| 가게 이름 설정 | 자동 답변에 들어갈 가게 이름 |

별점이 낮은 리뷰에는 답글을 자동으로 달지 않도록 별점 규칙을 나눠 두시는 방법도 있습니다.

## 3\. 템플릿 등록하기

**[템플릿 추가/변경]** 버튼을 눌러 **실제로 고객에게 등록할 답글 문구를 작성합니다.**  
먼저 **템플릿 그룹을 만든 후, 그룹 안에 템플릿을 추가하는 순서**로 진행합니다.

- **템플릿 그룹 추가**  
    그룹 이름을 입력하고 **[확인]** 버튼을 누르면 그룹이 생성됩니다. 하나의 그룹에 여러 개의 템플릿을 등록할 수 있습니다.

- **템플릿 추가**  
    고객에게 전달할 **답글 문구를 자유롭게 작성합니다.**

한 그룹에 여러 개의 템플릿을 등록하면, **등록된 템플릿 중 하나가 무작위로 선택되어 답글로 등록됩니다.** 이를 통해 모든 리뷰에 동일한 답글이 반복해서 등록되는 것을 방지할 수 있습니다.

## 매개변수 사용하기

답글 문구에 아래 매개변수를 넣으면 리뷰마다 다른 값으로 치환됩니다.

| 매개변수 | 치환되는 값 |
| --- | --- |
| `{{reviewerName}}` | 리뷰를 작성한 고객 이름 |
| `{{storeName}}` | 오터포스에 등록된 매장 이름 |

예를 들어 `{{reviewerName}}님, {{storeName}}입니다. 소중한 리뷰 감사합니다.`라고 작성하시면 고객 이름과 매장 이름이 자동으로 채워집니다.

## 템플릿 한 번에 올리기

템플릿을 여러 개 등록해야 한다면 **[일괄 업로드] 기능을 이용해 한 번에 등록할 수 있습니다.**

1. **[템플릿 다운로드]** 버튼을 눌러 엑셀 양식을 다운로드합니다.
2. 엑셀 양식의 **가이드를 확인하고 템플릿 내용을 작성합니다.**
3. 작성한 파일을 업로드하면 **템플릿이 자동으로 생성됩니다.**
