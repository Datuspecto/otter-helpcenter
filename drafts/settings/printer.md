**[설정 > 프린터]** 에서 매장에 연결된 프린터의 **연결 상태를 확인하고 영수증 출력 형식을 설정하실 수 있습니다.**

## 프린터 상태 확인

![설정 > 프린터 화면](/images/img-42.png)

프린터 이름과 함께 **현재 연결 상태가 표시됩니다.**  
상태가 **[오프라인]**으로 표시된다면 프린터의 **전원 및 연결 상태를 확인해 주세요.**

## 출력 매수 설정

프린터 오른쪽의 **[사본]** 값을 변경하면 영수증 **출력 매수를 조정할 수 있습니다.**  
주방용과 고객용으로 각각 출력하려면 **[2매]**로 설정해 주세요.

## 영수증 설정

| 항목 | 설명 |
| --- | --- |
| **영수증 수정** | 영수증 글자 크기를 조정합니다. |
| **원산지** | 영수증에 출력되는 원산지 내용을 작성합니다. |
| **영수증 출력 설정** | 주방용 영수증 출력 여부를 브랜드별로 설정합니다. |
| **영수증 옵션 그룹명 표기 유무** | 영수증에 옵션 그룹명을 표시할지 설정합니다. |
| **영수증에 가격 표시하기** | 영수증에 가격을 표시할지 설정합니다. |

원산지와 영수증 수정은 각 항목 오른쪽 **[수정]** 버튼으로 변경하시고, 나머지 세 항목은 토글로 켜고 끄시면 됩니다.

---

**예외 안내**

- **랜선(네트워크) 프린터를 쓰시는 경우** — 영수증 형식 수정이 지원되지 않습니다. 영수증 수정은 포스기 또는 PC에 프린터를 직접 연결해 사용하시는 경우에만 적용됩니다.
- **영수증이 출력되지 않는 경우** — [영수증이 출력되지 않을 때](/help/troubleshooting/receipt-not-printing)를 확인해 주세요.
