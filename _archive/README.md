# 보관용 — 실제 코드가 아닙니다

여기 있는 것은 설계를 확정하기 위해 만든 **프로토타입**입니다.
실제 서비스 코드는 `../app/` 입니다. 배포·수정은 그쪽에서 하세요.

## preview/
파이썬 정적 렌더러. 3단 레이아웃·예외 안내 박스·이미지 규격·죽은 링크 강등 같은
렌더링 규칙을 먼저 검증하는 데 썼습니다. 검증된 규칙은 `app/src/md.js`, `app/src/views.js`로 옮겼습니다.

실행: `python3 preview/build.py` 후 `preview/site/`를 정적 서빙

## editor-proto/
파일 기반 에디터 프로토타입. Tiptap 조합, 마크다운 왕복 변환, 표 편집, 예외 안내 블록을
검증하는 데 썼습니다. 이후 `app/admin-src/`로 옮기면서 파일 대신 D1을 읽고 쓰도록 바꿨습니다.

**이 프로토타입은 `drafts/*.md` 파일을 직접 수정합니다.** 지금은 D1이 원본이므로 실행하지 마세요.
